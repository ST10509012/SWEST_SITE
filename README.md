## Project Overview

SWEST KICKS is a Cape Town-based independent retail boutique specializing in exclusive, limited-edition sneakers and streetwear. This website provides a structured platform for displaying stock, handling customer enquiries, and displaying store locations.

---

## Website Goals and Objectives

- Drive local brand visibility across Cape Town.
- Provide an interactive product catalog and custom enquiry form.
- Display physical store information across multiple locations (CBD & Bellville).

---

## Key Features and Functionality

- Full HTML5 semantic markup across 5 pages.
- Working navigation menu across all pages.
- Interactive product enquiry form.
- Dual-location contact page with embedded maps.
